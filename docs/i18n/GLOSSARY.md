# GrideX UI glossary

## English

Use these terms consistently in UI strings, documentation and tests.

| Concept | Bulgarian | English |
| --- | --- | --- |
| safety envelope | безопасен работен диапазон | safety envelope |
| clamped command | ограничена команда | clamped command |
| Edge gateway | Edge шлюз | Edge gateway |
| sign in | Вход | Sign in |
| grid limit | Мрежов лимит | Grid limit |
| self-consumption | собствено потребление | Self-consumption |
| equivalent full cycles (EFC) | еквивалентни пълни цикли (EFC) | Equivalent full cycles (EFC) |
| quality flags | флагове за качество | Quality flags |
| flexible loads | управляеми товари | Flexible loads |
| heartbeat | сигнал за живот (heartbeat), first use | heartbeat |
| watchdog | watchdog таймер | watchdog timer |
| settlement | сетълмент | settlement |

Use Bulgarian site names in the Bulgarian locale. Keep protocol and brand names
such as Modbus, SOC, BMS, PCS, IBEX and OCPP untranslated.

## Български

Термините в таблицата са задължителни за интерфейса, документацията и тестовете.
При първа употреба „heartbeat“ се изписва „сигнал за живот (heartbeat)“.
За българския интерфейс се използват български имена на демонстрационните обекти.
